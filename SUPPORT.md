# Support

Latchway has not reached a supported production release.

- Use GitHub issues for reproducible bugs and narrowly scoped feature requests that contain no sensitive information.
- Use GitHub discussions, when enabled, for design and integration questions.
- Use `SECURITY.md` for any suspected vulnerability or sensitive diagnostic material.

Include the core commit, protocol contract version, client SDK and platform versions, database major version, deployment role, sanitized logs, request ID, and minimal reproduction. Never include provider credentials, master keys, identity or refresh tokens, DPoP proofs or private keys, raw attestation evidence, or prompt bodies.

Support and compatibility promises begin only when a release is listed as supported in `SECURITY.md` and `docs/implementation/COMPATIBILITY.md`.
