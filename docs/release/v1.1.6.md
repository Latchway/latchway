# Latchway server 1.1.6

This patch prevents Firebase Authentication signing-certificate rotation from
making identity verification temporarily unavailable.

- Follow the official Firebase Admin certificate semantics: parse each public
  certificate, select its RSA verification key by JWT `kid`, and validate the
  Firebase token's own timestamps independently.
- Accept Google's normal rotation overlap when the published map contains a
  certificate whose X.509 validity window has not started or has recently ended.
- Preserve bounded documents, strict PEM parsing, RSA key-size checks, RS256,
  issuer, audience, subject, token lifetime, protected outbound transport,
  conditional HTTP caching, PostgreSQL multi-replica caching and stale grace.
- Require only the Firebase project ID and Google's public certificates. This
  release adds no Firebase service-account secret or privileged Firebase API.

The complete Go suite, static analysis and affected identity race suite pass.
Regression coverage includes the full Firebase preset and lower-level key source
with simultaneously active, future and expired certificates.

Client contract 1.1.0, wire 1/2/3, contract bundle 1.1.2 and schema 33 are
unchanged. No database migration, application-policy activation or SDK update is
required.
